# Changes: Excel Export + Date Slider

## 1. Экспорт в Excel

### Backend
- Новый модуль: `backend/app/export.py`
- Эндпоинты:
  - `GET /api/v1/export/filials` — скачивание `filials.xlsx`
  - `GET /api/v1/export/holidays` — скачивание `holidays.xlsx`
- Форматы: `.xlsx` (OpenXML), создаются через `openpyxl`
- Стилизованные таблицы: заголовки синим, полосатые строки

### Frontend
- `frontend/src/services/api.js` — добавлен `exportApi` с двумя функциями
- `frontend/src/components/FilialsPage.jsx` — добавлены кнопки экспорта
- Иконка `DownloadIcon` в `Icons.jsx`

### Использование
В интерфейсе появилась секция **"Экспорт данных"** с двумя кнопками:
- 📥 Экспорт филиалов (Excel)
- 📥 Экспорт праздников (Excel)

При клике файл скачивается автоматически.

## 2. Слайдер дат ревизий

### Что изменилось
Раньше в карточке филиала показывался dropdown со всеми датами (прошлая, первая, последующие). Теперь:

- **Слайдер** — показывает **одну дату** одновременно
- Кнопки `◀` / `▶` для навигации между датами
- Progress dots — кликабельные точки для быстрого перехода
- Цветовая индикация:
  - **Прошлая** — серый
  - **Сегодня** — зелёный с бейджем "Сегодня"
  - **Будущая** — тёмно-зелёный

### Компонент
- `RevisionDatesSlider.jsx` — новый компонент
- Заменён `RevisionDatesDropdown` в `FilialCard.jsx`

### Визуал
- На обычной карточке: компактный слайдер
- На featured (главной) карточке: увеличенные элементы

## 3. Технические детали

### Backend
**requirements.txt** — добавлены зависимости:
```
openpyxl==3.1.5
xlsxwriter==3.2.0
```

**app/main.py** — подключён `export_router`

**app/export.py** — генерация Excel:
- `build_filials_excel()` — таблица с колонками:
  - ID, Название филиала, Первая ревизия, Предыдущая, Следующая, Статус, Недостача, Даты ревизий
- `build_holidays_excel()` — ID, Дата, Название

### Frontend
**api.js**:
- `rawApi` — для бинарных скачиваний (без `response.data` interceptor)
- `exportApi.downloadFilials()` / `downloadHolidays()` — create Blob → `<a download>`

**FilialCard.jsx**:
- Удалён `RevisionDatesDropdown`
- Добавлен `<RevisionDatesSlider />`

**FilialsPage.css**:
- `.exportControls` — панель с кнопками
- `.revisionSlider` — стили слайдера (стрелки, dots, цвета)

## 4. Как проверить

### Локально
```bash
# Backend
cd backend
source .venv/bin/activate  # или .venv\Scripts\Activate.ps1
uvicorn app.main:app --reload

# Frontend
cd frontend
npm run dev
```

1. Откройте `http://localhost:5173`
2. Создайте филиал (если нет)
3. В карточке филиала найдите секцию **"Даты ревизий"** — должен быть слайдер с одной датой и стрелками
4. Нажмите кнопки экспорта — скачаются `.xlsx` файлы

### На Vercel
Задеплойте backend и frontend отдельно (см. предыдущие инструкции).

## 6. Возможные проблемы

**Excel не скачивается, открывается в новой вкладке:**
- Убедитесь, что `VITE_API_URL` включает `/api/v1`
- Проверьте сетевые запросы в DevTools — должен быть `responseType: 'blob'`

**Слайдер не переключает даты:**
- Проверьте консоль браузера на ошибки
- Убедитесь, что `revision_dates` — массив строк ISO дат

**Стили слайдера сломаны:**
- Проверьте, что `FilialsPage.css` загружен
- На featured карточке могут быть ограничения по ширине
