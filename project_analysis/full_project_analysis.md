## Анализ

### README.md

**Описание проекта:**
Система управления ревизиями филиалов — полноценное веб-приложение для управления периодическими ревизиями филиалов с автоматическим планированием и уведомлениями.

**Возможности:**
- CRUD операции для филиалов и праздников
- Автоматическая генерация ревизий каждые 3 месяца
- Исключение выходных и праздничных дней
- Экспорт в Excel/CSV
- Email и Telegram уведомления

**Технологии:**
- Backend: Node.js + Express
- Frontend: React 18 + Vite
- Тестирование: Jest, Supertest
